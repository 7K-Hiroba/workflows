# Security policy

Report suspected workflow supply-chain, signing, admission, or runtime-smoke vulnerabilities privately to `7K-Hiroba/platform-security`. Do not open a public issue containing secrets or exploitable production details.

The library uses full-SHA consumers, CODEOWNERS, protected branch/tag rulesets, protected environments, keyless cosign, SLSA provenance, and signed test evidence. GitHub's native tag UI is not proof of gitsign identity; use the documented verification command.
